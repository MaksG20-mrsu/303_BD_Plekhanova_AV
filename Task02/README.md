# ETL-пайплайн для базы фильмов

Данный проект описывает ETL-процесс (извлечение, преобразование, загрузка),
который переносит сведения о фильмах, пользовательских оценках, тегах и
пользователях в базу данных SQLite.

## Что должно быть установлено

Чтобы `db_init.bat` отработал без ошибок, на машине нужны следующие компоненты:

### 1. Python версии 3.6 и новее
- **Как проверить**: выполнить `python3 --version` либо `python --version`
- **Где взять**: https://www.python.org/downloads/

### 2. SQLite3
- **Как проверить**: выполнить `sqlite3 --version`
- **Где взять**: https://www.sqlite.org/download.html
- **Примечание**: в большинстве операционных систем уже идёт в комплекте

### 3. Оболочка Bash
- **Linux / macOS**: подойдёт стандартный терминал (устанавливать ничего не нужно)
- **Windows**: используйте Git Bash, WSL или Cygwin
